# Drug Discovery Dashboard

Interactive Streamlit dashboard for:

- Disease → Target analysis
- Drug clinical development analysis
- Adverse event analytics
- Drug risk scoring
- Drug → Adverse Event Sankey visualization

## Features

### Disease & Target Analytics
- Disease → Target Sankey
- Sunburst charts
- Treemaps
- Heatmaps
- Top diseases
- Top targets

### Clinical Analytics
- Clinical stage distribution
- Trial phase analysis
- Trial study type visualization

### Safety Analytics
- Adverse event frequency
- Signal strength (Log Likelihood Ratio)
- Risk scoring model
- Drug risk ranking
- Drug → Adverse Event Sankey
